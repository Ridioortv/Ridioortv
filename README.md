### About me

I build **defensive security software** and help organizations understand and reduce their risk.

- 🛡️ **Information security** — vulnerability management, SIEM/SOAR, threat modeling (STRIDE) and detection coverage against MITRE ATT&CK.
- 🚀 **Founder of [tecnoros.ar](https://www.tecnoros.ar)**, a collaborative software startup from Rosario, and creator of **TERO Security**, a self-hosted security operations platform for small and mid-sized companies.
- ⚖️ **Computer forensics expert** (*perito informático*) for the courts of Rosario, Santa Fe — starting 2027.
- 💻 **Full-stack developer** — Python/FastAPI and TypeScript/React/Next.js, shipped with Docker and CI/CD.
- 🤖 I use AI coding agents in my daily workflow to ship faster without lowering the security bar.
